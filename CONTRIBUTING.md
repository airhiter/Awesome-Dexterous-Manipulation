# Contributing / 贡献指南

Thank you for helping maintain this reading list.

- Include a public paper, proceedings record, or full technical report directly relevant to dexterous manipulation. A demo alone is insufficient.
- Search for the title, acronym, arXiv ID or DOI before adding a paper. One paper, one primary category; an arXiv version and its conference version are the same entry.
- Provide the title, venue/status, concise technical focus, primary source URL and suggested reading priority. Distinguish preprints from accepted papers; cite an official record for venue changes.
- Prefer a DOI, proceedings page or arXiv abstract over a project page. Avoid tracking parameters. Update links when a more authoritative source becomes available.
- Keep English and Chinese README entries aligned. Update counts and the literature cutoff when appropriate.
- Do not upload copyrighted paper PDFs without permission.

## 中文说明

仅收录公开论文或完整技术报告；新增前按标题、简称、arXiv ID 或 DOI 去重。预印本与正式发表版本合并为同一条记录。每篇只归入一个主方向，提供简洁技术描述、原文入口及发表状态。更新时同步维护中英文 README、编号与统计数量。欢迎纠正未经确认的会议归属和链接。
